## How it works

`main.ts` (Node 22, stdlib only) writes the entry to `/output/entry.txt`:

> Monday review: my alarm went off, my train didn't, and my 9am meeting could've been an email. One star. I want a refund on the week.

132 characters, one line, no title, no explanation — exactly what the gate asks for.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
